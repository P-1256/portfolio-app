# Portfolio App

A modern full stack developer portfolio application built using React, Node.js, Express, and MongoDB.

## Features

- Modern responsive UI
- React Router navigation
- Animated interface using Framer Motion
- Dynamic project fetching from backend
- MongoDB integration
- REST API architecture
- Login and registration pages
- Clean reusable component structure
- Competitive programming section
- Contact page with social links

---

## Tech Stack

### Frontend

- React
- React Router
- Tailwind CSS
- Axios
- Framer Motion

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
